# Cinema 4D Plugins

A collection of Cinema 4D plugins by bijodima.

## PoleWire 1.0

Build pole-and-wire lines along splines using your own pole models. Includes terrain placement, corner and end models, individual wire settings, pole overrides, and model presets.

- [Installation and user guide](PoleWire/README.md)
- [Plugin source](PoleWire/)
- [Watch the PoleWire tutorial on YouTube](https://youtu.be/XoqRJlL90O8)

To install PoleWire, download this repository, copy the complete `PoleWire` folder into your Cinema 4D preferences `plugins` directory, and restart Cinema 4D. Open **Extensions > Pole Wire** or search for **Pole Wire** with **Shift+C**.

See the plugin guide for compatibility details and limitations. Disable **Spline Preview** before rendering to generate wire geometry.
